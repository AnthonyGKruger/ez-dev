# Share image (og-image)

`public/media/og-image.png` (1200x630) is rendered from `og.html` in this
folder. To change the wording, edit `og.html` (eyebrow, headline, footer
line) and run:

```
node docs/og-image/render.cjs
```

Keep the headline in step with the hero copy in `content/en/site.json`.
